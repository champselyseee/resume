# Сайт-визитка

Одна страница на трёх языках (русский, английский, французский) со светлой и тёмной темой.
Никаких сборок и установок: это обычные файлы, которые браузер открывает как есть.

## Файлы

| Файл | Что внутри |
|------|-----------|
| `content.js` | **Все тексты и ссылки.** Обычно правишь только этот файл. |
| `index.html` | Структура страницы (какие блоки и в каком порядке). |
| `styles.css` | Оформление: цвета, шрифты, отступы, анимации. |
| `logos.css` | Логотипы, вшитые в текст. Руками не правится. |
| `app.js` | Логика: переключение языка и темы, заставка при загрузке. |
| `photo.svg` | Заглушка вместо фотографии. |
| `favicon.svg` | Иконка вкладки браузера. |

## Как посмотреть сайт

Дважды кликни по `index.html` — он откроется в браузере.

## Как поменять текст

Открой `content.js` в любом текстовом редакторе. Внутри три раздела: `ru`, `en`, `fr` —
русский, английский и французский. Меняй текст между кавычками.

Пара правил, чтобы ничего не сломалось:

- меняй только то, что **внутри кавычек**: `name: "Иван Петров",`
- запятую в конце строки не убирай;
- списки в квадратных скобках `[ ... ]` можно удлинять и укорачивать, копируя соседний
  блок целиком (вместе с фигурными скобками и запятой).

Если после правки страница стала пустой — значит потерялась кавычка или запятая.
Нажми `Ctrl+Shift+J` (Windows) или `Cmd+Option+J` (Mac) — браузер покажет, в какой строке ошибка.

## Что где лежит в `content.js`

| Блок | За что отвечает |
|------|-----------------|
| `statement` | Главная фраза под именем |
| `education` | Учебные заведения |
| `courses` | Курсы и тренинги |
| `experience` | Места работы |
| `cases` | Кейс-чемпионаты и конкурсы |
| `skillGroups` | Навыки, разбитые на группы |
| `projects` | Проекты — кнопки со ссылками |

**Контакты — исключение.** Ссылки на почту и соцсети лежат прямо в `index.html`
(раздел «03 — Контакты» и две кнопки на первом экране). Чтобы поменять —
найди там нужную строку и замени адрес в `href="…"`.

## Как добавить проект

В `content.js` найди `projects` и заполни:

```js
{
  name: "Название проекта",
  note: "Одна строка о том, что там",
  url: "https://ссылка",   // пусто — строка покажется, но кликать будет нечего
  logo: "",
}
```

## Как устроены логотипы

Картинки логотипов не лежат отдельными файлами — они переведены в текст
и вшиты в `logos.css`. Так сайт работает одним куском: ничего не потеряется
при переносе и не отвалится при выкладке.

В `content.js` в поле `logo` пишется короткое имя, например:

```js
logo: "ukrtb",       // возьмёт логотип из logos.css
logo: "",            // логотипа нет — встанет квадратик с первой буквой
```

Сейчас вшито шесть: `telegram`, `vk`, `max`, `instagram`, `ukrtb`, `finuniver`.

Чтобы добавить новый — положи PNG в папку `logos` и попроси пересобрать
`logos.css`: картинка уменьшается до 96 точек, сжимается и вшивается.
Логотипы брендов бери только с их официальных страниц, не из поиска картинок.

## Как поставить своё фото

1. Положи снимок в эту же папку, например `photo.jpg` (лучше вертикальный, ~800×1000 точек).
2. В `content.js` в самом верху впиши имя файла:

```js
const PHOTO = "photo.jpg";
```

## Как поменять цвета

В начале `styles.css` есть два блока: `html[data-theme="light"]` (светлая тема)
и `html[data-theme="dark"]` (тёмная). Меняешь значения вроде `--paper` (бумага),
`--ink` (чернила), `--red` (красная краска для пометок) — меняется весь сайт сразу.

## Как выложить в интернет (Vercel)

Сайт статический, никакой сборки не нужно.

1. Загрузить папку в репозиторий на GitHub.
2. На [vercel.com](https://vercel.com): **Add New → Project**, выбрать репозиторий.
3. Framework Preset — **Other**, поля Build Command и Output Directory оставить пустыми.
4. **Deploy**.

После этого каждое обновление в GitHub автоматически обновляет сайт.
